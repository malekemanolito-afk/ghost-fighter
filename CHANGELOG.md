# Changelog

All notable changes to Ghost Fighter will be documented in this file.

## [1.0.0] - 2026-08-08

### Added
- Initial release of Ghost Fighter
- Complete game loop and state management
- Player character with multiple attack types
- Three enemy types: Lost Soul, Shadow Ghost, Spirit Archer
- Boss fight: The Soul Reaper
- Wave-based progression system (5 waves)
- XP and leveling system
- Combo counter and scoring system
- Particle effects and screen shake
- Main menu, pause menu, game over, and victory screens
- HUD with health, energy, level, and combo display
- Audio system (framework for sound effects)
- Settings and save system
- Responsive canvas rendering
- Debug mode (F3)
- Camera system with smooth follow
- Collision detection
- Combat system with knockback

### Controls
- A/← Move Left
- D/→ Move Right
- W/↑ Jump
- S/↓ Crouch
- J/Z Basic Attack
- K/X Heavy Attack
- L/C Special Attack
- SPACE Dash
- ESC Pause
- F3 Toggle Debug

### Features
- 60 FPS target performance
- Pixel-art aesthetic
- Arcade-style gameplay
- Progressive difficulty
- High score tracking
- Settings persistence
